# AI Engineering Harness v1.1.2

## Summary

Version 1.1.2 adds a simple Windows double-click installation entry point while
preserving the existing deterministic PowerShell bootstrap.

## Changes

- Added root-level `INSTALAR.cmd` for normal Windows users.
- Made the launcher location-independent and safe for paths containing spaces.
- Preserved the PowerShell bootstrap exit code and kept the final result visible.
- Included and required the launcher in portable distributions.
- Clarified the difference between installation, development tests, and host chat integration.

## Requirements

- Python 3.11 or newer must already be installed and available on `PATH`.
- Internet access may be required for the first dependency installation.
- Private GitHub access is required only when obtaining the source through the private repository.

## Compatibility

No runtime API or project-data format changes. Existing `projects/` content and the
v1.1.1 release remain unchanged.
