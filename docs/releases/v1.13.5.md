# HARNESS v1.13.5

Fresh-PC Installer Hardening

## Problems fixed

1. Installer Python-version validation

setup.ps1 detectaba Python pero no proporcionaba una señalización fiable
para versiones inferiores al contrato soportado.

Ahora:

Python < 3.11:
exit 2
PYTHON_VERSION_UNSUPPORTED

Python >= 3.11:
supera el version gate y continúa con el flujo correspondiente.

- setup.ps1 actualmente replica explícitamente 3.11;
- pyproject remains the product Python contract;
- ambos deben mantenerse sincronizados.

## Python packaging

Antes setuptools incluía:

engine*

Ahora incluye:

engine*
adapters*
core*

Esto elimina la dependencia accidental de que imports Python de provider/core
se resuelvan desde el CWD/source tree.

## Package data

"*" = ["*.yaml", "*.md"]

Permite distribuir recursos YAML/Markdown dentro de Python packages, incluyendo los recursos runtime requeridos bajo core.
(Esto no empaqueta todos los archivos del portable root).
