# AI Engineering Harness v1.5.1 (Bootstrap Hotfix)

Este es un parche de runtime y bootstrap humano. No incluye nuevas funcionalidades.

## Defecto Detectado
Durante la inicialización de HARNESS-0022, se detectó que el especialista `harness-maintainer` existía y estaba autorizado en la `Authority Matrix`, pero faltaba su materialización física (Schema, Profile y Prompt) en `core/specialists/`. 

Esto producía el siguiente fallo crítico en tiempo de ejecución:
`Planning failed: Specialist nonexistent: harness-maintainer`

## Resolución de Delegación Circular
La ausencia del especialista provocó una paradoja de **delegación circular**: el orquestador no podía usar al especialista para arreglar la infraestructura (porque el especialista mismo era lo que faltaba), impidiendo que el Harness se reparara a sí mismo.

Para romper el bloqueo, se realizó un **bootstrap humano explícito** que inyectó manualmente:
- `core/specialists/harness-maintainer/specialist.yaml`
- `core/specialists/harness-maintainer/prompt.md`
