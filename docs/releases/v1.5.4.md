# Release v1.5.4

**Date**: 2026-08-30

## Fixes & Hardening

*   **Antigravity CLI Executor Diagnostics**: `AntigravityCliExecutor` ahora diferencia entre un código de salida `0` (host SUCCESS) y una respuesta de agente útil. Un estado `SUCCESS` con una respuesta vacía o de solo espacios (ej. abortos internos de `agy` por límite de iteraciones) se trata explícitamente como una ejecución incompleta (lanzando `RuntimeError`).
*   **Bounded Stderr Preservation**: El `stderr` del host ya no se descarta cuando el proceso termina con éxito. Ahora se preserva en `AntigravityResponse.metadata`, acotado de manera determinística a 8192 caracteres (con indicador de truncado si se excede). Esto protege el entorno de memoria a la vez que resguarda logs y warnings emitidos por herramientas que previamente se perdían.
*   **Metadata Extensión**: `metadata` ahora garantiza almacenar `status`, `num_turns`, `duration`, `usage`, `returncode`, y `stderr`.
*   **Status Limitations**: Esta versión **NO** afirma solucionar la causa interna de que `agy` responda vacío. Su propósito es exponer ese evento como fallo rastreable con telemetría adjunta, sacándolo de las sombras del enmascaramiento de host.
*   **HARNESS-0022**: Sigue sin resolverse (bloqueado operativamente) y NO forma parte de este release funcional.

## Testing & Maintenance

*   13 escenarios nuevos en `test_cli_executor.py` para asegurar validación tipo y truncado seguro de diagnóstico.
