# Release v1.1.1

## Summary

Corrective portability release for clean-machine recovery and development testing.

## Fixed

- The export-builder test now supplies an identity only to its temporary Git commit.
- A clean PC no longer needs global Git `user.name` or `user.email` configuration to
  run the full test suite.
- Test and installation documentation now distinguish the Git executable requirement
  from optional user identity configuration.

## Validation

- Fresh private-repository clone recovered 49 commits and tags `v1.0.0` and `v1.1.0`.
- Portable installer completed with `STATUS: READY` on Python 3.14.5.
- Recovery suite reproduced the missing-identity failure before the correction.
- Corrected suite completed without global Git identity: 455 passed, 2 skipped.
- Ruff and version-consistency checks passed.

## Compatibility

No runtime API or project-data format changes. Existing `projects/` content is unaffected.
