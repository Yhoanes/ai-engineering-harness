# Release v1.3.0

## Dynamic Selection and Delegation of Specialists

This release introduces a fully dynamic, canonical-driven approach to specialist assignment (HARNESS-0019), removing hardcoded agent mapping.

**Key Features & Mechanics:**
- **Dynamic Selection:** The Orchestrator's Router now dynamically discovers specialists directly from `core/specialists/*/specialist.yaml`.
- **Workflow & Authority Validation:** Profiles are matched against their capabilities and then strictly filtered using `core/workflows/*/workflow.yaml` to ensure the agent has explicit authorization for the target workflow.
- **Assignment Preservation:** Pre-approved assignments within Task Contracts are respected and never arbitrarily overridden by the system.
- **Safe Human Escalation:** In cases of ties, low confidence, lack of authority, or non-existent specialists, the system deterministically escalates to human approval via the `discuss` workflow.
- **Backward Compatibility:** `\new-project` and Antigravity adapter flows remain fully supported, conversational, and read-only until explicit human authorization is granted.
