# HARNESS v1.13.7

Antigravity CLI Installer Detection

## Installer UX

El instalador ahora detecta si gy está disponible mediante:

Get-Command agy -ErrorAction SilentlyContinue

Cuando existe:

Antigravity CLI ........ PASS

Cuando no existe:

Antigravity CLI ........ NOT INSTALLED

y muestra un aviso indicando que el provider de Antigravity requiere gy.

## Important behavior

La ausencia de gy:

- NO falla la instalación del Harness;
- NO cambia STATUS READY del Harness core;
- NO instala nada automáticamente;
- NO descarga herramientas;
- NO modifica PATH;
- NO autentica usuarios;
- NO abre navegador.
