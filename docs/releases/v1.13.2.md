## Documented Limitations
The use of this flag is accepted for the current provider support profile under documented isolation limitations:
- **native isolation**: false
- **WorktreeSandbox**: Relies on a git worktree, not an OS sandbox.
- **absolute-path writes**: Writes outside the workspace may still be possible if executed via absolute path.
- **external terminal side effects**: Not universally observable.
- **physical read isolation outside workspace**: NOT PROVEN.
- **network egress sandbox**: NOT PROVEN.
- **post-validation coverage**: Covers repository/worktree state only, not arbitrary OS effects.
