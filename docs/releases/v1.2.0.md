# Release 1.2.0

## Features
- **Antigravity Native Integration (HARNESS-0018)**: Native support for Google Antigravity.
  - The `harness-evolution-advisor` and `general-advisor` are now registered natively in `.agents/`.
  - Added `harness-advisor` skill enabling `/advisor`, `/new-project`, and `/evolve-harness` slash commands.
  - Strict governance rules apply to Antigravity interactions to maintain a read-only stance for conversational advisors, requiring a Task Contract and human approval for modifications.
  - Diagnostics and portable distributions updated to support these components.
