# AI Engineering Harness v1.6.0
## Harness 2.0 Architecture Foundation

Esta versión marca el inicio formal de la migración hacia **Harness 2.0**.

### Cambios Principales

- **Principio Fundamental**: "Harness is a provider-neutral governance layer, not an agent runtime."
- **Separación Conceptual**: Se introduce la separación estricta entre *project workspace* (código fuente real) y *Harness metadata* (contextos de IA, contratos, evidencias, memoria).
- **MetadataPaths (`core/context/metadata_paths.py`)**: Se introduce una nueva abstracción encargada de gobernar exclusivamente dónde viven los metadatos del Harness. No gestiona código del proyecto.
- **Validaciones Centralizadas**: La seguridad de las rutas y la validación de `project_id` y `task_id` ha sido extraída de los componentes y centralizada en `MetadataPaths` para eliminar duplicidad de expresiones regulares.
- **Resolución de Alias**: El manejador canónico de metadatos internos del sistema es ahora `.harness-internal`, resolviendo transparentemente el legacy alias `_harness-internal`.
- **Integración de Componentes**:
  - `ContextLoader` migrado íntegramente a `MetadataPaths`.
  - El adaptador legacy (Antigravity adapter) y el `AutonomousRunner` abandonaron la construcción manual de rutas harcodeadas de metadata.
  - El validador post-ejecución `validate_allowed_paths_post.py` ahora comparte la política central de `resolve_safe_path`.

### Notas de Migración Físicas

- **Ningún archivo ha sido movido** a la carpeta futura `.harness/`.
- La carpeta `projects/` todavía no ha sido limpiada físicamente. Se siguen guardando temporalmente los metadatos de tareas, pero ahora todos apuntan a la abstracción.
- Aún no existe una *provider interface* agnóstica de facto. Antigravity sigue siendo el runtime legacy actual acoplado.

### Desviaciones de Tareas
- La tarea estructural **HARNESS-0025** fue ejecutada de manera intervenida directamente, por lo que fue declarada y documentada como `completed_with_deviation`.
- La tarea **HARNESS-0022** permanece congelada y fuera de este release.

Esta versión es el cimiento, no es Harness 2.0 completo.
