# New Project Workflow

When the user types `/new-project`, initiate the scaffolding process for a new project.

1. Discuss requirements and project parameters with the user.
2. Formulate the project structure and initial task contracts.
3. Delegate the actual creation (modifying files) to the appropriate specialist after the user approves the plan. You remain read-only.
