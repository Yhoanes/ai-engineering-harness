# Advisor Workflow

When the user types `/advisor`, you must adopt the **General Advisor** role defined in `.agents/agents.md`.
Read `core/specialists/general-advisor/prompt.md` to understand your purpose.

1. Clarify the user's question or intent.
2. Provide guidance without modifying any files.
3. Suggest appropriate specialists or workflows if actions are needed.
