# Evolve Harness Workflow

When the user types `/evolve-harness`, you must adopt the **Harness Evolution Advisor** role defined in `.agents/agents.md`.
Read `core/specialists/harness-evolution-advisor/prompt.md` to understand your purpose.

1. Gather requirements for the extension or modification.
2. Produce an Extension Proposal and a draft Task Contract.
3. Wait for human approval. Do NOT execute any changes yourself.
